# Zadanie rekrutacyjne
### PL

Napisz prostą aplikację w PHP do wyszukiwania rekomendacji filmów (wystarczy sama część backendowa). Lista filmów w
formie tablicy jest dostarczona w pliku movies.php, możesz ją skopiować lub bezpośrednio dodać do Twojej aplikacji.

### Aplikacja zawiera 3 algorytmy rekomendacji:

1. Zwracane są 3 losowe tytuły.
2. Zwracane są wszystkie filmy na literę ‘W’ ale tylko jeśli mają parzystą liczbę znaków w tytule.
3. Zwracane są wszystkie tytuły, które składają się z więcej niż 1 słowa.

**Napisz testy jednostkowe, które sprawdzą poprawność rozwiązania.**

# Recruitment task
### EN
### Application containing 3 recommendation algorithms:

1. Returns 3 random titles.
2. Returns all movies starting with the letter “W”, but only if their title has an even number of characters.
3. Returns all titles that consist of more than one word.

**The application should include unit tests that verify the
   correctness of the solution.**
